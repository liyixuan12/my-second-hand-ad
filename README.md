# 二手商品画廊

一个简单的二手商品展示网站，支持点击查看大图和轮播功能。

## 🚀 快速开始

1. 启动本地服务器：
   ```bash
   python3 -m http.server 8000
   ```

2. 打开浏览器访问：`http://localhost:8000`

## 📝 配置商品

编辑 `main.yaml` 文件：

```yaml
items:
  - item: 商品名称
    cover: img/封面图片.jpeg
    images:
      - img/大图1.jpeg
      - img/大图2.jpeg
    price: €价格
    description: 商品描述
```

## 📁 文件结构

```
.
├── index.html          # 主页面
├── style.css          # 样式文件
├── script.js          # 功能脚本
├── main.yaml          # 商品配置
├── img/               # 图片文件夹
└── README.md          # 说明文档
```

## ✨ 功能特性

- 🖼️ **画廊展示** - 网格布局展示商品
- 🔍 **点击放大** - 点击商品查看大图
- 🎠 **图片轮播** - 支持多张图片轮播浏览
- ⌨️ **键盘操作** - 支持方向键和ESC键
- 📱 **响应式设计** - 手机和桌面都适配
- 🔄 **动态加载** - 修改配置文件后刷新即可更新

## 🎯 使用技巧

1. **图片建议**：使用 JPEG 格式，建议大小不超过 2MB
2. **配置文件**：只需要编辑 `main.yaml` 文件
3. **实时更新**：修改配置文件后直接刷新浏览器即可看到效果
4. **调试信息**：按 F12 打开开发者控制台查看详细日志
